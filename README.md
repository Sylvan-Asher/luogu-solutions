## 怎么添加题解

1. 点击上面的篇目，再打开对应分类文件夹。
2. 在 GitHub 页面点击 **Add file → Upload files**，上传自己的 `.c` 或 `.cpp` 源码。
3. 点击 **Commit changes** 保存。

建议用题号命名，例如 `P1001.cpp`。同一题的文字题解可命名为 `P1001.md`，格式参考 [题解模板](题解模板.md)。编译生成的 `.exe`、`.o` 等文件无需上传。

每个分类里的 `README.md` 包含对应的洛谷题单链接，也让尚未添加代码的分类能够显示在 GitHub 中。
